# Repository of Souls

A curated collection of SOUL.md persona files — each one a complete, voiced character that transforms how an AI assistant speaks, thinks, and acts.

Every persona is produced by a multi-stage pipeline (research → namer → writer → reviewer → refiner → final reviewer) and stored as a terse, self-contained markdown file. No templates, no fill-in-the-blanks. Each soul is distinct.

## Browse

Open `site/index.html` locally, or visit the hosted version.

## Use

Download any `.md` from `archive/` and place it in your agent's configuration directory as `SOUL.md`.

## Contribute

See `AGENTS.md` for the pipeline spec. New seeds start at Stage T1.
