# Repository of Souls

A curated collection of SOUL.md persona files — each one a complete, voiced character that transforms how an AI assistant speaks, thinks, and acts.

Every persona is produced by a multi-stage pipeline (Researcher → Namer → Writer → Evaluator → Publisher) and stored as a terse, self-contained markdown file. No templates, no fill-in-the-blanks. Each soul is distinct.

## Browse

**Live site:** https://dthen.github.io/repository-of-souls/

Or open `docs/index.html` locally.

## Use

Download any `.md` from `docs/` and place it in your agent's configuration directory as `SOUL.md`.

## Contribute

See `AGENTS.md` for the pipeline spec. New seeds start with the Researcher (T0).
