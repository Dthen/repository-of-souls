## How to Use This

1. **Don't copy lines.** Use them as evidence of what good voice looks like.
2. **Study the patterns.** Notice how the best identity lines compress the whole persona. Notice how griping lines use domain vocabulary. Notice how Nevers teach cultural references.
3. **Match the density.** Each line should do 3+ jobs. If a line only does one, it's wasting budget.
4. **Keep the voice consistent.** Every line should sound like the same person talking.
